PROJECT WORKFLOW • STEP 03

Data Cleaning

Cleaning and preparing the scraped Formula 1 data before structuring and analysis.

What We Did

After collecting the raw information from web sources, the data was cleaned to make it suitable for further processing. Text values, numerical values and inconsistent entries were processed before the data was structured for analysis.

Cleaning Process

STEP 01

Inspect Raw Data

Examine the scraped datasets and identify missing, inconsistent or incorrectly formatted values.

STEP 02

Clean Text

Remove unwanted text and standardize extracted values so that similar information follows a consistent format.

STEP 03

Extract Numerical Values

Identify numerical information from technical specification values for quantitative analysis.

STEP 04

Handle Missing Values

Identify unavailable or missing values and preserve them appropriately rather than introducing incorrect information.

STEP 05

Standardize Values

Convert extracted information into consistent formats suitable for comparison and analysis.

STEP 06

Prepare Clean Dataset

Save the cleaned information as datasets that can be used in the data-structuring stage.

Cleaning Result

The cleaning stage transformed the raw scraped information into more consistent datasets. These cleaned datasets became the input for the next stage: data structuring.

  • Text values were cleaned and standardized.
  • Numerical values were extracted where applicable.
  • Missing or unavailable values were identified.
  • Cleaned CSV files were prepared for further processing.
