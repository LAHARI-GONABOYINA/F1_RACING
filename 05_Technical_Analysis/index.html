TECHNICAL ANALYSIS

Analysis of Formula 1 car technical specifications across seasons

What We Did

The technical analysis stage focuses on examining the technical specifications collected from Formula 1 car and team sources. The specifications were cleaned, structured and compared across different seasons to identify measurable technical changes.

Technical Analysis Process

01. Load Structured Data

The structured technical specification data was loaded for analysis.

02. Select Technical Attributes

Important specifications such as weight, weight distribution, MGU-K and MGU-H were selected for comparison.

03. Compare Seasons

Technical specifications from different seasons were compared to identify changes.

04. Quantitative Analysis

Numerical technical values were extracted where available to measure changes between seasons.

05. Visualize Changes

Technical changes were represented using charts to make season-to-season differences easier to understand.

06. Interpret Results

The observed technical changes were interpreted together with the available performance data.

The measured weight changed from 798 kg in 2024 to 800 kg in 2025.

Other common numerical specifications available in the collected data did not show a measurable change.

MGU-K and MGU-H numerical specifications were available in the 2025 extracted data but were not available in the 2024 extracted dataset.

Interpretation

The technical analysis identified only limited measurable changes between the available 2024 and 2025 McLaren data.

The car weight increased by 2 kg, while the common technical specifications available for both seasons showed no measurable numerical change.

The technical findings were later compared with performance results to investigate whether technical changes were associated with changes in team performance.

Because the analysis contains only two McLaren seasons, the results should be interpreted as an observed association rather than proof of causation.
