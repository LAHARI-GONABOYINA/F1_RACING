PROJECT WORKFLOW • STEP 01

Web Scraping

Collection of Formula 1 technical specifications, team performance and race-result information from web sources for further analysis.

What We Did

Web scraping was the first stage of the project. Information related to Formula 1 cars, teams and race performance was collected from publicly available web sources. The collected information was then stored as raw data and used in the later stages of cleaning, structuring and analysis.

Scraping Process

STEP 01

Select Web Sources

Identify relevant Formula 1 web pages containing technical specifications, team standings and race-result information.

STEP 02

Send Web Request

Python requests are used to access the selected web pages and retrieve their HTML content.

STEP 03

Extract Information

BeautifulSoup is used to identify and extract relevant information from the HTML structure.

STEP 04

Collect Data

Technical specifications, team performance and race-result information are collected into structured records.

STEP 05

Store Raw Data

The extracted information is stored in CSV files before data cleaning and transformation.

STEP 06

Prepare for Analysis

The collected raw data is passed to the next stages of the project for cleaning, structuring and analysis.

Data Collected

Technical Specifications

Formula 1 car specifications such as weight, weight distribution, engine and power-unit related specifications.

Team Performance

Constructor standings and team points were collected for performance comparison.

Race Results

Race-level information was collected for analyzing wins and team performance trends.

Driver Performance

Driver classification and performance information was collected as part of the project dataset.
